## 📌 Descripción del Proyecto

Sistema en consola para la gestión de tareas (To-Do List) desarrollado en Node.js. Permite almacenar, agregar, completar y filtrar tareas por categoría utilizando arreglos de JavaScript.

---

## ⚙️ Funcionalidades Implementadas

* **`listarTareas()`**: Muestra la lista general de tareas con su estado (pendiente o completada).
* **`agregarTarea(titulo, descripcion, categoria)`**: Crea una nueva tarea asignándole un ID autoincrementable y agregándola al arreglo general.
* **`completarTarea(id)`**: Busca una tarea por su ID único y actualiza su estado a completada.
* **`listarPorCategoria(categoria)`**: Filtra e imprime las tareas que coinciden con la categoría solicitada, ignorando diferencias entre mayúsculas y minúsculas.
